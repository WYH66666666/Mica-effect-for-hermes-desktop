原理
三层结构，一个跟随器
┌────────────────────────────┐ │ Hermes Desktop（半透明） │ ← 目标窗口 ├────────────────────────────┤ │ 遮罩窗 Frost Underlay │ ← Electron 窗口 │ （DWM Mica 材质） │ 点击穿透 · 无边框 └────────────────────────────┘ ↓ 事件驱动 SetWindowPos FrostTracker.exe（WinEventHook）

FROST UNDERLAY
三行命令跑起来
快速开始
# 安装 electron
npm install electron --save-dev

# 一键启动，自动跟随 Hermes
powershell -ExecutionPolicy Bypass -File start.ps1

# 或手动
npx electron .

配置项
FROST_TARGET　　跟随的进程名　　　　默认 Hermes
FROST_MATERIAL　　材质 mica / acrylic　　默认 mica
FROST_DARK　　　　　1 = 跟随系统深色模式
ELECTRON_PATH　　　electron.exe 路径　　　自动探测
